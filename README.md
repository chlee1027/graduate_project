# 🏋️ Fitness AI Recommender (AI PT 코치 운동 추천 시스템)

## 📌 프로젝트 개요

사용자의 건강 정보, 컨디션, 환경 및 과거 운동 이력을 기반으로 **개인화된 운동을 추천하는 AI 코칭 시스템**입니다. 
단순한 부위별 안배를 넘어 전문 PT 코치처럼 세부 근육 단위의 균형을 맞추고 친절한 가이드를 제공합니다.

---

## 🎯 주요 성과 및 업데이트 (2026.06.01)

### 🧠 추천 알고리즘 v3.0 (PT 코치 모드) - NEW!
*   **세부 근육 단위 정밀 분석**: 대분류 부위(가슴, 하체 등)뿐만 아니라 소분류 근육(햄스트링, 광배근 등)의 수행 이력을 7일 단위로 추적하여 균형 잡힌 신체 발달을 유도합니다.
*   **지능형 코칭 사유 (Reasoning)**: "최근에 광배근 자극이 부족했네요!"와 같이 데이터에 기반한 친절한 추천 사유를 생성하여 신뢰도를 높였습니다.
*   **용어 로컬라이징**: 어려운 전문 용어를 "대퇴사두(앞허벅지)"와 같이 쉬운 한글로 변환하여 제공합니다.

### 📱 추천 UI/UX 고도화
*   **인앱 가이드 접근성**: 운동 정보 바로 아래에 유튜브 가이드 영상 링크를 배치하여 즉시 시청이 가능하게 개선했습니다.
*   **추천 사유 토글**: 사용자가 원할 때 추천 이유를 펼쳐볼 수 있는 전용 UI 섹션을 추가했습니다.

### 🧬 확장된 운동 데이터베이스 (총 41종)
*   **다양한 운동 풀 확보**: 버피 테스트(전신), 아놀드 프레스(어깨), 힙 쓰러스트(둔근) 등 전문적인 운동 41종을 구축하여 추천의 다양성을 확보했습니다.
*   **회복/유연성 세션**: 캣 카우, 코브라 스트레칭 등 액티브 레스트를 위한 스트레칭 데이터가 보강되었습니다.

## ⚙️ 기술 스택

### Frontend
*   **Framework**: Expo (React Native SDK 54+) + TypeScript
*   **State**: Zustand (User & Session store)
*   **Networking**: Axios (localtunnel 연동)

### Backend
*   **Framework**: FastAPI (Python 3.12+)
*   **Database**: PostgreSQL (Docker-Compose)
*   **AI Engine**: Contextual Bandit (ε-greedy) + Granular Muscle Priority Logic
