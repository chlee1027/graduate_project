#  graduate_project– AI 기반 맞춤형 헬스코치 시스템

### 📄 프로젝트 개요(Overview):

본 프로젝트는 개인의 건강정보와 스마트폰 센서 데이터를 기반으로,
AI가 개인 맞춤형 운동량을 예측하고 실시간 동작 인식을 통해
사용자에게 최적화된 운동 가이드를 제공하는 헬스코치 서비스입니다.

### ✨ 주요 기능(Features):

 - 건강데이터 기반 운동량 예측 모델

 - 스쿼트(가속도+자이로), 윗몸일으키기(자이로) 실시간 동작 인식

 - 예측 결과를 세트·횟수 형태 맞춤 운동량으로 변환

 - 운동 패턴 분석 기반 맞춤형 피드백·알림 제공

 - 사용자 운동데이터 기록 및 시각화
