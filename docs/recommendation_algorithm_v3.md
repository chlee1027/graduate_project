# 🧠 Workout Recommendation Algorithm v3.0 (PT Coach Mode)

본 문서는 Fitness AI Recommender의 **v3.0 'PT 코치 모드'** 알고리즘 설계 및 업데이트 내용을 설명합니다.

## 1. 개요
v3.0은 단순한 부위별 안배를 넘어, 실제 전문 트레이너가 옆에서 조언하듯 **세부 근육 단위의 균형**을 맞추고 **친절한 설명**을 제공하는 것을 목표로 합니다.

## 2. 주요 업데이트 사항

### 2.1 2단계 정밀 우선순위 시스템 (Granular Priority)
기존의 대분류(Major Part) 중심 로직에 소분류(Sub-target Muscle) 가중치를 결합했습니다.
- **1단계 (분할 루틴 유지)**: 최근 7일간 운동량이 적은 대분류 부위(가슴, 등, 하체 등)에 기본 점수 부여.
- **2단계 (세부 근육 밸런스)**: 같은 부위 내에서도 최근에 수행하지 않은 세부 근육(예: 하체 중 '햄스트링', 가슴 중 '상부 가슴' 등)에 **+15점의 보너스 점수**를 부여하여 정교한 신체 발달을 유도합니다.

### 2.2 PT 코치 브레인 (Coaching Logic)
추천 결과에 대한 신뢰도를 높이기 위해 '이유' 생성 로직을 강화했습니다.
- **지능형 사유 생성**: 보너스 점수가 부여된 근육을 파악하여 사용자가 이해하기 쉬운 코멘트를 생성합니다.
- **로컬라이징**: "Quadriceps"와 같은 전문 용어를 "대퇴사두(앞허벅지)"와 같이 친숙한 한글 명칭으로 자동 변환하여 제공합니다.

### 2.3 데이터베이스 확장 (v3.0 Seed)
추천의 다양성을 확보하기 위해 운동 풀을 **총 41종**으로 확대했습니다.
- **홈트레이닝**: 버피, 마운틴 클라이머 등 고강도 맨몸 운동 추가.
- **웨이트 트레이닝**: 아놀드 프레스, 힙 쓰러스트, 스컬 크러셔 등 타겟팅이 명확한 전문 동작 보강.
- **회복 세션**: 캣 카우, 코브라 스트레칭 등 유연성 및 회복을 위한 스트레칭 데이터 강화.

## 3. 알고리즘 워크플로우

1.  **데이터 수집**: 최근 7일간의 `ExerciseLog`에서 수행된 모든 `target_parts` 및 `sub_target_parts` 카운트.
2.  **후보군 필터링**: 장소(Gym/Home), 사용 가능 시간, 현재 통증 부위, 장비 보유 여부 체크.
3.  **점수 계산 (Priority Score)**:
    - 대분류 순위 점수 (10~60점)
    - 세부 근육 보너스 (최대 15점)
4.  **최종 선택**: 과거 완료율(Bandit Reward)과 현재 우선순위 점수를 합산하여 최적의 운동 결정.
5.  **사유 매핑**: 선정된 운동의 특성에 맞춰 한글화된 PT 코멘트 매핑.

## 4. 기대 효과
- **편식 없는 운동**: 사용자가 선호하는 운동만 반복하는 것을 방지하고 신체 전반의 균형을 맞춤.
- **심리적 유대감**: 단순 데이터 나열이 아닌 '나를 위한 조언'이라는 느낌을 주어 운동 지속성 향상.
